How I run my own agents.

Nerve Center is my own agent system. I’ve built 100+ agents for it since February 2026. The drawing shows structure only. Every part fails eventually, so every failure needs a catch. The lettered marks are four of them.

Read the drawing as text
  1. The operator (me, on phone or desktop) works through the cockpit, a TypeScript UI.
  2. The cockpit puts work on a message bus, which queues it. A frozen modal here is caught by the watchdog (C).
  3. A supervising daemon runs the agent sessions and restarts any that die (A).
  4. Inside the sessions, one lead agent fans work out to specialist agents, one per job.
  5. Sessions retrieve from a memory graph first, and read and write durable state, where tombstones reject a stale tab’s write (B).
  6. Email and messages from the agents to other people pass one send gate, which waits for my yes by default (D).
  7. A watchdog layer wraps everything and checks that work actually got done.
  1. A

    A: Sessions die. A guard brings them back.

    Agent sessions crash and get killed mid-task. The supervising daemon notices the missing session and restarts it from durable state, and the work picks up where it stopped.

  2. B

    B: A stale tab cannot overwrite the present.

    A closed session leaves a tombstone. When an old browser tab tries to write to it later, the write is rejected and the dead session stays dead.

  3. C

    C: A frozen modal cannot stall the queue for long.

    One blocking dialog can freeze a session and everything queued behind it. The watchdog checks that work got done. When work stops, it clears the stall and the queue drains.

  4. D

    D: One gate for what goes out under my name.

    Every email or message my agents send to another person passes one gate. By default it waits for my yes on the exact text. I’ve signed three narrow standing approvals, each with a cap and a kill switch. The teardown names them.

The incidents behind these guards, and what changed after each one, are written up in the agent safety case study ↗.
