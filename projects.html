    Details and links: Nerve Center: the AI organization JD runs his work on

    Nerve Center is the private multi-agent system JD designed, built and operates on a Mac mini. The public showcase page (snapshot 2026-11-09) reports 30+ agents in daily production, 100+ built over time, 310 background jobs (65 of them watchdogs) and 1,092 shipped-work log entries in 30 days.     claude-bug-squash

    Live

    A gated autonomous bug fixer: triage, a fix in an isolated worktree, red-to-green proof, and a three-seat review before anything merges.

    • Claude Code
    • git worktrees
    • bash/Python
    • Claude Code plugin
    Details and links: claude-bug-squash

    Point Claude Code at a repo and report a bug. It triages and assigns a risk tier, writes a fix in a throwaway git worktree, proves the bug goes red to green, then runs the real diff through blast-radius caps, a never-touch deny-list and a 3-seat adversarial review panel.
