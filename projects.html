    clawdling

  • Open source · MIT

    ccstitch

    A local trace viewer for Claude Code. It repairs the orphaned spans from claude-code#99607 and nests claude -p runs under the tool call that started them.

    • View repo: ccstitch (github.com)→

  • Bug specs · MIT

    claude-code-behavior-specs

  • Open source · MIT

    warden

    Lets an agent fix things on its own only when the fix can be undone and a check proves it worked. Rolls back on failure. 28 offline tests.

    • View repo: warden (github.com)→
