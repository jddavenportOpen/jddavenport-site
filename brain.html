The live brain

Every dot is a real part of the AI operating system I run, counted live from the inventory it publishes about itself. Names and data are hidden on purpose: this shows the architecture, not the contents.

I've built 100+ agents for this system since February 2026. The counts below are only the agent definitions registered in the inventory today, and many of them are not in daily use.

How this works: the page reads /api/metrics, a server-side filter over the inventory the system republishes whenever it ships. It forwards numbers only. No agent, skill or job name, and no content, ever reaches your browser. The dots are placed from those counts; the moving pulses illustrate the routing path (orchestrator, domain agent, bus, specialist) and are not a message feed. Sparklines: daily model activity and daily shipped-work log entries over the last 30 days. If the live request fails you see the snapshot from 2026-11-26.
