The AI operating system I run my work on

Snapshot · 2026-09-24

One orchestrator, 48 specialized agents, a durable job queue, and a gate on every irreversible action. It runs 24/7 on a Mac mini and republishes its own inventory when it ships.

Amber dots are work moving through the system.
How work moves
  1. A request lands: a Telegram voice note, a cockpit message, or a scheduled job firing on its own.
  2. The orchestrator triages it and picks the agent that owns it. The router picks the model.
  3. It becomes a job row in Postgres. A durable runner claims it, and agents coordinate over the bus.
  4. An agent does the work, in its own git worktree if it touches code, reading memory and state as it goes.
  5. Anything irreversible or outward-facing stops at the gate until I say yes.
  6. The result ships through the relay with a receipt. Watchdogs keep checking after it lands.

The map is drawn by hand from the running system: component names are real, hostnames and credentials are left out. The counts load live from capabilities.json, which the system regenerates and republishes on its own. If that request fails you see the snapshot from 2026-09-24.
